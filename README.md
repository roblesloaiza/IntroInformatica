# BD-111 · Guía de estudio · Unidades 1–3

Paquete listo para publicar con GitHub Pages.

## Publicar
1. Cree un repositorio público en GitHub.
2. Suba `index.html`, `.nojekyll` y este `README.md` a la raíz.
3. Vaya a **Settings → Pages**.
4. En **Build and deployment**, seleccione **Deploy from a branch**.
5. Seleccione la rama `main` y `/ (root)`.
6. Guarde y espere a que GitHub muestre la URL publicada.

## Dependencias externas
Las fotografías se cargan desde Wikimedia Commons/Unsplash y el modelo 3D desde Sketchfab. Por ello, el navegador necesita acceso a Internet para mostrar esos recursos. El HTML, estilos, navegación y contenido no requieren compilación ni dependencias locales.
